# 카싱크 (CarSync) 서비스 기획 포트폴리오 웹페이지

`카싱크(CarSync)` 서비스 기획서 내용을 기반으로 만든, PPT 형식의 스크롤 프레젠테이션 웹페이지입니다.
슬라이드를 넘기듯 세로로 스크롤하며 표지 → 문제 정의 → 미션 → 솔루션 4종 → 경쟁사 비교 → 로드맵 순으로 내용을 보여줍니다.

## 파일 구성

```
carsync-portfolio/
├── index.html    # 페이지 구조 (semantic HTML)
├── style.css     # 디자인 시스템 · 레이아웃 · 반응형
├── script.js     # 상단 목차 현재 위치 표시(scroll-spy)
└── README.md     # 이 문서
```

세 파일은 서로 상대 경로로 연결되어 있으므로, 세 파일을 같은 폴더에 둔 채로 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## HTML 구조 (semantic markup)

- `<header>` — 상단 고정 바. 로고와 슬라이드 목차 내비게이션(`<nav>`)
- `<main>` — 전체 슬라이드를 담는 본문. 슬라이드마다 `<section>`으로 분리
  - `#cover` 표지
  - `#problem` 문제 정의 (3가지 issue 카드)
  - `#mission` 미션 3가지 (다크 배경 슬라이드)
  - `#solution` 4대 솔루션 (공임비 비교 / 시한폭탄 레이더 / 양심 정밀케어 리포트 / 단골 보증 네트워크)
  - `#compare` 차별점 비교 `<table>`
  - `#roadmap` Phase 1~3 로드맵
- `<footer>` — 마무리 문구 및 출처 메모

각 섹션은 `aria-labelledby`로 제목과 연결되어 있고, 표는 `scope`와 `caption`을 사용해 스크린리더 접근성을 챙겼습니다.

## 디자인 콘셉트

- **모티프**: 동네 정비소 견적서(영수증), 계기판(속도계), 도로의 점선 차선 — 자동차 정비라는 소재에서 직접 끌어온 시각 장치를 사용했습니다.
- **색상**

  | 변수 | 색상값 | 용도 |
  |---|---|---|
  | `--paper` | `#eeeae1` | 종이/견적서 배경 |
  | `--ink` | `#15191a` | 본문 잉크 |
  | `--steel` | `#2b3a3f` | 정비소 다크 패널(미션·비교표 슬라이드) |
  | `--signal` | `#d9662b` | 경고/강조(공임비, 레이더 항목) |
  | `--trust` | `#3f6b52` | 승인/신뢰(원터치 승인 스탬프) |

- **타이포그래피**: 제목은 `Black Han Sans`(간판·도장 느낌의 굵은 한글 서체), 본문은 `Noto Serif KR`(신뢰감 있는 명조체)로 두 가지 서체만 사용했습니다. Google Fonts CDN에서 불러오므로 인터넷 연결이 필요합니다.
- **스크롤 스냅**: 각 `<section>`이 한 화면(슬라이드)에 대응하도록 `scroll-snap`을 적용했습니다. `prefers-reduced-motion`을 설정한 사용자에게는 자동으로 비활성화됩니다.

## 화면 1. 메인 홈

### 대한민국 평균 공임비 & 10만km 시한폭탄 레이더

차량의 현재 상태와 정비 비용을 한 화면에서 확인할 수 있도록 구성합니다.

**핵심 목적**
- 평균 공임비를 먼저 공개해 정비 비용에 대한 불안 감소
- 주행거리 기반으로 정비가 필요한 소모품을 직관적으로 표시
- 위험도가 높은 항목부터 사용자의 행동을 유도
- AI 정비 주치의와 정비 예약으로 자연스럽게 연결

### 핵심 UX

① **공임 투명성**
"정비소에서 얼마를 받아야 하는지 모르겠다."라는 차주의 불안을 해결하기 위해 평균 공임비를 첫 화면에 공개합니다.

② **위험도 시각화**
차량의 주행거리와 정비 이력을 기반으로 소모품 상태를 🔴 위험 / 🟡 경고 / 🟢 정상 3단계로 구분하여 사용자가 현재 정비 우선순위를 빠르게 파악할 수 있도록 합니다.

③ **행동 유도**
위험 항목에서 바로 [AI 정비 주치의 문진 시작]으로 연결하여, 위험 인지 → 원인 확인 → 정비 예약이라는 자연스러운 사용자 흐름을 만듭니다.

## 화면 2. AI 정비 주치의

### 1:1 상황 역추적 문진 & 팩트 비교

비현실적인 주행 중 소리 녹음이나 복잡한 차량 진단 대신, 사용자가 실제로 경험한 상황을 선택하고 AI가 증상을 단계적으로 좁혀가는 대화형 UI입니다.

**핵심 목적**
- 사용자의 주행 상황 기반 증상 분류
- 복잡한 자동차 용어를 일반적인 언어로 변환
- 의심 부위를 단계적으로 압축
- 공식 센터와 카싱크 정비 비용 비교
- 진단 → 예약(노쇼 방지 예약금)까지 연결

### UI Wireframe

```text
┌────────────────────────────────────────────────────────┐
│  ◀  AI 정비 주치의 진단실                               │
├────────────────────────────────────────────────────────┤
│                                                        │
│  🤖 [카싱크 주치의]                                     │
│  진훈 차주님, 주행 중 어떤 이상 증상이 느껴지시나요?    │
│                                                        │
│                  [방지턱 넘을 때 찌걱/달그락 소리] 👤  │
│                                                        │
│  🤖 [카싱크 주치의]                                     │
│  11만km 주행 시점의 방지턱 소음은 하부 부싱 경화와      │
│  활대링크 유격 확률이 88%입니다.                        │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 💡 정비 비용 팩트 비교                            │  │
│  ├──────────────────────────────────────────────────┤  │
│  │ • 공식 센터 어셈블리 통교체: 약 60만 ~ 80만 원    │  │
│  │ • 카싱크 골목 장인 핀셋 교체: 약 18만 ~ 24만 원    │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  방치 시 주행 안정성이 무너지고 타이어 편마모로 이어져   │
│  더 큰 수리비가 발생합니다.                             │
│                                                        │
│  [부품 선발주 & 예약금(2만원)으로 당일 정비 예약하기]   │
└────────────────────────────────────────────────────────┘
```

### 핵심 UX

① **상황 중심 문진**
자동차 지식이 없는 사용자에게 부품명을 직접 입력하게 하지 않고, 방지턱을 넘을 때 / 브레이크를 밟을 때 / 변속할 때 등 사용자가 이해하기 쉬운 상황 중심 질문으로 접근합니다.

② **진단 결과를 확률로 표현**
AI가 증상을 분석한 뒤 의심되는 부위를 좁혀 사용자에게 보여줍니다.

③ **수리비 비교**
공식 센터의 통교체 방식과 카싱크 제휴 정비소의 개별 부품 교체 비용을 비교하여 사용자가 수리 방식과 비용 차이를 직관적으로 이해할 수 있도록 합니다.

④ **바로 예약 (노쇼 방지 예약금 결제)**
진단 결과 확인 후 [부품 선발주 → 노쇼 방지 예약금(2만 원) 결제 → 정비소 리프트 타임슬롯 확정]까지 매끄럽게 연결합니다.

## 화면 3. 사장님 전용 B2B 리포트

### 고객 실시간 변수 브리핑 & 후결제 뷰

정비 현장에서 예상하지 못한 부식·고착·파손 등의 변수가 발생했을 때, 정비사가 사진과 작업 소견을 고객에게 전달하고 예상이 계산된 상태에서 추가 작업을 진행하는 화면입니다.

**핵심 목적**
- 현장 변수의 사진 증빙
- 정비사의 작업 소견 전달
- 예약금 차감 적용 및 최종 후결제 산정 금액 사전 고지
- 고객의 실시간 승인/확인
- 정비 분쟁 예방 및 작업 이력 자동 기록

### UI Wireframe

```text
┌────────────────────────────────────────────────────────┐
│ 🔧 [성수 현대카서비스] 정밀케어 현장 변수 브리핑        │
├────────────────────────────────────────────────────────┤
│ 📌 예약금 20,000원 결제 완료 (최종 결제 시 자동 차감)   │
│                                                        │
│ 📢 [현장 정비사 브리핑]                                 │
│ "진훈 차주님, 하체 찌걱거림 원인은 로워암 부싱 경화가   │
│ 맞습니다. 다만, 염화칼슘 부식으로 고정 볼트가 고착되어  │
│ 특수 해제 작업이 함께 필요합니다."                     │
│                                                        │
│ ┌──────────────────────┐    ┌──────────────────────┐   │
│ │  [📷 고착 볼트 사진] │    │  [📷 찢어진 부싱]     │   │
│ └──────────────────────┘    └──────────────────────┘   │
│                                                        │
│ 🛠️ 최종 예상 정비 내역                                  │
│ • 로워암 + 활대링크 핀셋 교체: 180,000원                │
│ • [현장 변수] 고착 볼트 산소 해제 특수 공임: +20,000원  │
│ ────────────────────────────────────────────────────── │
│ • 총 정비 예정 금액: 200,000원                          │
│ • 예약금 차감 적용: -20,000원                           │
│ 💳 현장 최종 후결제 예정액: 180,000원                   │
│                                                        │
│ [ 🟢 내용 확인했습니다 (작업 계속 진행) ]                │
└────────────────────────────────────────────────────────┘
```

### 핵심 UX

① **사진 기반 증빙**
정비사가 복잡한 설명을 장시간 작성하지 않고 현장 사진을 촬영하여 고객에게 전달합니다.

② **최소 조작**
기름 묻은 손으로 사용하는 환경을 고려하여 사진 촬영 → 작업 항목 선택 → 추가 공임 선택 정도의 최소한의 조작으로 리포트를 작성할 수 있도록 설계합니다.

③ **투명한 예약금 차감 및 후결제 안내**
사전에 결제한 2만 원 예약금이 차감된 최종 결제 예정 금액을 명확히 제시하여 고객이 납득 가능한 가격 신뢰도를 확보합니다.

④ **분쟁 예방**
현장 변수 발견 → 증빙 발송 → 예상 금액 확인 → 고객 승인 → 작업 진행 → 현장 후결제 순으로 처리하여 차주와 정비사 사이의 비용 분쟁을 완전히 방지합니다.

## 4. UI 인터랙션 및 시스템 처리 흐름

### 전체 사용자 여정

```text

             ├─ 📷 현장 사진 촬영 (고착 볼트, 파손 부위)

             ▼

        ├─ 알림 확인 (현장 사진 & 상세 소견)

        │
        ▼

        │
        ├─ 현장 잔금 후결제 진행
        ├─ 교체 부품 & 정비 이력 디지털 차트 자동 저장
        └─ 지인 단골 보증서 발급
```

## 5. 핵심 서비스 구조

| 사용자 | 핵심 문제 | CarSync 해결책 |

## 6. 핵심 UX 가치

- **차주에게**: "내 차에 지금 무엇이 필요한지, 얼마가 적정한지, 왜 정비 비용이 추가되었는지 투명하게 알 수 있다."
- **정비사에게**: "노쇼 걱정 없이 예약받고, 현장에서 발생하는 추가 공임의 정당성을 사진과 데이터로 증명할 수 있다."
- **CarSync에게**: "차주와 정비사 사이의 정보 비대칭과 불신을 데이터와 증빙 시스템으로 완벽히 해결한다."

## 7. 한 줄 서비스 정의

> CarSync는 AI 차량 진단, 정비비 투명화, 노쇼 방지 예약금 및 현장 증빙 브리핑을 하나로 연결하여 차주와 동네 정비소 사이의 정보 비대칭을 해결하는 자동차 정비 플랫폼입니다.
