# 카싱크 (CarSync) 서비스 기획 포트폴리오 웹페이지

`카싱크(CarSync)` 서비스 기획서 내용을 기반으로 만든, PPT 형식의 스크롤 프레젠테이션 웹페이지입니다.
슬라이드를 넘기듯 세로로 스크롤하며 표지 → 문제 정의 → 미션 → 솔루션 4종 → 경쟁사 비교 → 로드맵 순으로 내용을 보여줍니다.

## 파일 구성

```
carsync-portfolio/
├── index.html   # 페이지 구조 (semantic HTML)
├── style.css    # 디자인 시스템 · 레이아웃 · 반응형
├── script.js    # 상단 목차 현재 위치 표시(scroll-spy)
└── README.md    # 이 문서
```

세 파일은 서로 상대 경로로 연결되어 있으므로, 세 파일을 같은 폴더에 둔 채로 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## HTML 구조 (semantic markup)

- `<header>` — 상단 고정 바. 로고와 슬라이드 목차 내비게이션(`<nav>`)
- `<main>` — 전체 슬라이드를 담는 본문. 슬라이드마다 `<section>`으로 분리
  - `#cover` 표지
  - `#problem` 문제 정의 (3가지 issue 카드)
  - `mission` 미션 3가지 (다크 배경 슬라이드)
  - `solution` 4대 솔루션 (공임비 비교 / 시한폭탄 레이더 / 양심 정밀케어 리포트 / 단골 보증 네트워크)
  - `#compare` 차별점 비교 `<table>`
  - `#roadmap` Phase 1~3 로드맵
- `<footer>` — 마무리 문구 및 출처 메모

각 섹션은 `aria-labelledby`로 제목과 연결되어 있고, 표는 `scope`와 `caption`을 사용해 스크린리더 접근성을 챙겼습니다.

## 디자인 콘셉트

- **모티프**: 동네 정비소 견적서(영수증), 계기판(속도계), 도로의 점선 차선 — 자동차 정비라는 소재에서 직접 끌어온 시각 장치를 사용했습니다.
- **색상**
  - `--paper #eeeae1` 종이/견적서 배경
  - `--ink #15191a` 본문 잉크
  - `--steel #2b3a3f` 정비소 다크 패널(미션·비교표 슬라이드)
  - `--signal #d9662b` 경고/강조(공임비, 레이더 항목)
  - `--trust #3f6b52` 승인/신뢰(원터치 승인 스탬프)
- **타이포그래피**: 제목은 `Black Han Sans`(간판·도장 느낌의 굵은 한글 서체), 본문은 `Noto Serif KR`(신뢰감 있는 명조체)로 두 가지 서체만 사용했습니다. Google Fonts CDN에서 불러오므로 인터넷 연결이 필요합니다.
- **스크롤 스냅**: 각 `<section>`이 한 화면(슬라이드)에 대응하도록 `scroll-snap`을 적용했습니다. `prefers-reduced-motion`을 설정한 사용자에게는 자동으로 비활성화됩니다.

### 대한민국 평균 공임비 & 10만km 시한폭탄 레이더

차량의 현재 상태와 정비 비용을 한 화면에서 확인할 수 있도록 구성합니다.

**핵심 목적**

* 평균 공임비를 먼저 공개해 정비 비용에 대한 불안 감소
* 주행거리 기반으로 정비가 필요한 소모품을 직관적으로 표시
* 위험도가 높은 항목부터 사용자의 행동을 유도
* AI 정비 주치의와 정비 예약으로 자연스럽게 연결

> "정비소에서 얼마를 받아야 하는지 모르겠다."

* 🔴 위험
* 🟡 경고
* 🟢 정상

**③ 행동 유도**

위험 항목에서 바로 **[AI 정비 주치의 문진 시작]**으로 연결하여,

> **위험 인지 → 원인 확인 → 정비 예약**

이라는 자연스러운 사용자 흐름을 만듭니다.

# 화면 2. AI 정비 주치의

### 1:1 상황 역추적 문진 & 팩트 비교

비현실적인 **주행 중 소리 녹음**이나 복잡한 차량 진단 대신, 사용자가 실제로 경험한 상황을 선택하고 AI가 증상을 단계적으로 좁혀가는 대화형 UI입니다.

### 핵심 목적

* 사용자의 주행 상황 기반 증상 분류
* 복잡한 자동차 용어를 일반적인 언어로 변환
* 의심 부위를 단계적으로 압축
* 공식 센터와 카싱크 정비 비용 비교
* 진단 → 예약까지 연결

### UI Wireframe

```text
┌────────────────────────────────────────────────────────┐
│  ◀  AI 정비 주치의 진단실                              │
├────────────────────────────────────────────────────────┤
│                                                        │
│  🤖 [카싱크 주치의]                                    │
│  진훈 차주님, 주행 중 어떤 이상 증상이 느껴지시나요?   │
│                                                        │
│                  [방지턱 넘을 때 찌걱/달그락 소리] 👤  │
│                                                        │
│  🤖 [카싱크 주치의]                                    │
│  11만km 주행 시점의 방지턱 소음은 하부 부싱 경화와     │
│  활대링크 유격 확률이 88%입니다.                       │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 💡 정비 비용 팩트 비교                           │  │
│  ├──────────────────────────────────────────────────┤  │
│  │ • 공식 센터 어셈블리 통교체: 약 60만 ~ 80만 원   │  │
│  │ • 카싱크 골목 장인 핀셋 교체: 약 18만 ~ 24만 원   │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  방치 시 주행 안정성이 무너지고 타이어 편마모로 이어져  │
│  더 큰 수리비가 발생합니다.                            │
│                                                        │
│  [부품 선발주로 대기 없이 당일 정비 예약하기 (터치)]    │

```

### 핵심 UX

**① 상황 중심 문진**

자동차 지식이 없는 사용자에게 부품명을 직접 입력하게 하지 않고,

* 방지턱을 넘을 때
* 브레이크를 밟을 때
* 변속할 때
* 시동을 걸 때
* 고속 주행할 때

등 **사용자가 이해하기 쉬운 상황 중심 질문**으로 접근합니다.

**② 진단 결과를 확률로 표현**

AI가 증상을 분석한 뒤 의심되는 부위를 좁혀 사용자에게 보여줍니다.

> 방지턱 소음
> ↓
> 하부 부싱 경화 / 활대링크 유격
> ↓
> 정비 필요성 확인

**③ 수리비 비교**

공식 센터의 통교체 방식과 카싱크 제휴 정비소의 개별 부품 교체 비용을 비교하여 사용자가 **수리 방식과 비용 차이를 직관적으로 이해**할 수 있도록 합니다.

**④ 바로 예약**

진단 결과 확인 후 별도의 검색 과정을 거치지 않고

> **[부품 선발주 → 정비소 예약 → 리프트 시간 확정]**

까지 연결합니다.

# 화면 3. 사장님 전용 B2B 리포트

### 고객 실시간 승인 화면

정비 현장에서 예상하지 못한 **부식·고착·파손 등의 변수가 발생했을 때**, 정비사가 사진과 작업 내용을 고객에게 전달하고 추가 작업을 승인받는 화면입니다.

### 핵심 목적

* 현장 변수의 사진 증빙
* 정비사의 작업 소견 전달
* 추가 작업 및 비용 사전 고지
* 고객의 실시간 승인
* 정비 분쟁 예방
* 작업 이력 자동 기록

### UI Wireframe

```text
┌────────────────────────────────────────────────────────┐
│  🔧 [성수 현대카서비스] 정밀케어 현장 변수 브리핑       │
├────────────────────────────────────────────────────────┤
│  "차주님, 로워암 탈거 중 부식 고착 변수가 확인되었습니다"│
│                                                        │
│  [ 📷 고착 볼트 현장 사진 ]   [ 📷 찢어진 고무 부싱 ]  │
│                                                        │
│  📋 현장 소견:                                         │
│  "하부 염화칼슘 부식으로 고정 볼트가 나사선에 고착되어  │
│  일반 탈거 시 볼트 파손 위험이 큽니다. 산소 가열 및    │
│  특수 탭 작업을 병행해 안전하게 탈거합니다."           │
│                                                        │
│  • 작업 항목: 고착 볼트 특수 해제 작업                 │
│  • 추가 비용: +20,000원 (표준 기술 공임 적용)          │
│                                                        │
│  [ 🟢 내용 확인 완료 / 추가 작업 승인 및 계속 진행 ]   │
└────────────────────────────────────────────────────────┘
```

### 핵심 UX

**① 사진 기반 증빙**

정비사가 복잡한 설명을 장시간 작성하지 않고 **현장 사진을 촬영**하여 고객에게 전달합니다.

**② 최소 조작**

현장에서 기름 묻은 손으로 사용하는 상황을 고려하여,

> **사진 촬영 → 작업 항목 선택 → 추가 공임 선택**

정도의 최소한의 조작으로 리포트를 작성할 수 있도록 설계합니다.

**③ 고객 즉시 승인**

고객은

1. 현장 사진 확인
2. 정비사 소견 확인
3. 추가 비용 확인
4. 승인

의 순서로 빠르게 판단할 수 있습니다.

**④ 분쟁 예방**

추가 공임이 발생한 뒤 사후에 통보하는 것이 아니라,

> **현장 변수 발견 → 증빙 → 비용 안내 → 고객 승인 → 작업 진행**

순으로 처리하여 차주와 정비사 사이의 비용 분쟁을 줄입니다.

# 4. UI의 핵심 작동 원리

## 01. 메인 화면

### 공임 투명성 + 위험 인지

> **"얼마가 적정한지 모르겠다."**

차주의 가장 큰 불안을 해결하기 위해 **평균 공임비를 전면에 노출**합니다.

동시에 주행거리 기반 위험 부품을 보여주어 사용자가 자신의 차량에서 **지금 무엇을 점검해야 하는지** 바로 알 수 있도록 합니다.

**사용자 흐름**

```text
공임 확인
   ↓
차량 위험도 확인
   ↓
위험 부품 발견
   ↓
AI 정비 주치의
```

---

## 02. AI 정비 주치의

### 증상 압축 + 비용 비교

사용자가 복잡한 자동차 용어를 몰라도 실제 주행 상황을 선택하면서 자신의 증상을 설명할 수 있도록 합니다.

AI는 입력된 상황과 차량 정보를 기반으로 의심 부위를 좁혀가고, 동시에 **정비 비용 차이를 숫자로 보여줍니다.**

**사용자 흐름**

```text
주행 상황 선택
   ↓
AI 문진
   ↓
의심 부위 압축
   ↓
공식 센터 vs 카싱크 비용 비교
   ↓
정비 필요성 판단
   ↓
정비 예약
```

---

## 03. 변수 승인 화면

### 현장 증빙 + 실시간 합의

정비 과정에서 예상하지 못한 문제가 발견되었을 때 정비사가 임의로 작업을 진행하지 않고,

```text
현장 변수 발생
      ↓
사진 촬영
      ↓
정비사 소견 작성
      ↓
추가 작업 항목 선택
      ↓
추가 비용 안내
      ↓
고객 승인
      ↓
작업 진행
```

의 프로세스를 적용합니다.

이를 통해 **정비사에게는 정당한 추가 공임을 청구할 수 있는 근거**를 제공하고, 차주에게는 **비용이 왜 추가되었는지 확인할 수 있는 증거**를 제공합니다.

## 1. UI 설계 핵심 원칙

### 1-1. 정보 투명성

앱 접속 즉시 **대한민국 평균 공임비**를 전면에 노출하여 정비 과정에서 발생하는 **바가지 요금에 대한 불안**을 사전에 해소합니다.

### 1-2. 직관적 손실 회피

> **"지금 소모품 정밀케어 15만 원 vs 방치 후 통교체 200만 원"**

단순히 정비를 권유하는 것이 아니라, **현재 정비 비용과 방치했을 때 발생할 수 있는 비용을 비교**하여 사용자가 정비의 필요성을 직관적으로 이해하도록 설계합니다.

시각적 위험 게이지와 차량 데이터를 활용해 **손실 회피(Loss Aversion)**를 UX에 적용합니다.

### 1-3. 현장 최적화 UX

기름 묻은 손으로 작업하는 정비사의 사용 환경을 고려하여 텍스트 입력을 최소화합니다.

* 📷 사진 촬영
* 👆 원터치 옵션 선택
* 📋 사전 정의된 작업 항목
* 💰 추가 공임 자동 계산

등을 활용해 **최소한의 조작으로 현장 변수를 기록하고 고객에게 전달**할 수 있도록 설계합니다.
