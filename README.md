# 카싱크 (CarSync) 서비스 기획 포트폴리오 웹페이지

`카싱크(CarSync)` 서비스 기획서 내용을 기반으로 만든, PPT 형식의 스크롤 프레젠테이션 웹페이지입니다.
슬라이드를 넘기듯 세로로 스크롤하며 표지 → 문제 정의 → 미션 → 솔루션 4종 → 경쟁사 비교 → 로드맵 순으로 내용을 보여줍니다.

## 파일 구성

```
carsync-portfolio/
├── index.html   # 페이지 구조 (semantic HTML)
├── style.css    # 디자인 시스템 · 레이아웃 · 반응형
├── script.js    # 상단 목차 현재 위치 표시(scroll-spy)
└── README.md    # 이 문서
```

세 파일은 서로 상대 경로로 연결되어 있으므로, 세 파일을 같은 폴더에 둔 채로 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## HTML 구조 (semantic markup)

- `<header>` — 상단 고정 바. 로고와 슬라이드 목차 내비게이션(`<nav>`)
- `<main>` — 전체 슬라이드를 담는 본문. 슬라이드마다 `<section>`으로 분리
  - `#cover` 표지
  - `#problem` 문제 정의 (3가지 issue 카드)
  - `mission` 미션 3가지 (다크 배경 슬라이드)
  - `solution` 4대 솔루션 (공임비 비교 / 시한폭탄 레이더 / 양심 정밀케어 리포트 / 단골 보증 네트워크)
  - `#compare` 차별점 비교 `<table>`
  - `#roadmap` Phase 1~3 로드맵
- `<footer>` — 마무리 문구 및 출처 메모

각 섹션은 `aria-labelledby`로 제목과 연결되어 있고, 표는 `scope`와 `caption`을 사용해 스크린리더 접근성을 챙겼습니다.

## 디자인 콘셉트

- **모티프**: 동네 정비소 견적서(영수증), 계기판(속도계), 도로의 점선 차선 — 자동차 정비라는 소재에서 직접 끌어온 시각 장치를 사용했습니다.
- **색상**
  - `--paper #eeeae1` 종이/견적서 배경
  - `--ink #15191a` 본문 잉크
  - `--steel #2b3a3f` 정비소 다크 패널(미션·비교표 슬라이드)
  - `--signal #d9662b` 경고/강조(공임비, 레이더 항목)
  - `--trust #3f6b52` 승인/신뢰(원터치 승인 스탬프)
- **타이포그래피**: 제목은 `Black Han Sans`(간판·도장 느낌의 굵은 한글 서체), 본문은 `Noto Serif KR`(신뢰감 있는 명조체)로 두 가지 서체만 사용했습니다. Google Fonts CDN에서 불러오므로 인터넷 연결이 필요합니다.
- **스크롤 스냅**: 각 `<section>`이 한 화면(슬라이드)에 대응하도록 `scroll-snap`을 적용했습니다. `prefers-reduced-motion`을 설정한 사용자에게는 자동으로 비활성화됩니다.

## 커스터마이징 가이드

1. **문구 수정**: `index.html` 안의 한글 텍스트를 그대로 찾아 바꾸면 됩니다. 구조(태그)는 건드릴 필요 없습니다.
2. **숫자/비용 예시**: `03 — Solution 1`의 공임비 막대그래프(`.cost-compare`)는 `style="--w:36%"`처럼 인라인으로 막대 길이를 지정합니다. 실제 데이터가 생기면 이 퍼센트 값과 표시 금액을 함께 수정하세요.
3. **색상 톤 변경**: `style.css` 최상단 `:root` 안의 CSS 변수만 바꾸면 전체 배색이 함께 바뀝니다.
4. **소유자 정보**: 하단 `<footer>`의 `site-footer__meta` 문구는 포트폴리오 제출자 이름/연락처 등으로 자유롭게 교체해 사용하세요.
